This service is an automated version of the Private Room Scanner. It automatically scans user-owned private rooms every 5 to 10 minutes as long as the private room is active.

  **Detailed Breakdown**
  
<AccordionGroup>
  <Accordion title="Room Visits">

  **Definition**: This metric reflects the total number of visits a user has made into various rooms over the selected period.
  
  **How It Works**: Each time searched user enters a room, it counts as a visit regardless how many times user leaves and joins.

  **Purpose**: Understanding the number of room visits can help you understand how frequently searched user are engaging in a private room and identifying patterns in their activities.
  </Accordion>

  <Accordion title="Unique Rooms">

    **Definition**: This metric indicates the number of different rooms searched user has interacted within the timeframe.

    **How It Works**: Each room is counted only once regardless of how many times you entered it. For instance, if you visit Room A and Room B, that counts as two unique rooms even if you visit Room A multiple times.
  </Accordion>
</AccordionGroup>

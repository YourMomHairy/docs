The **Automated Private Room Scanner** enables the monitoring of private rooms that the user owns without the need to scan them manually. This feature will automatically scan active private rooms set up by the user at regular intervals of **5 to 10 minutes**.

This feature is particularly useful for users who want to track private room activity without manually scanning. It allows the user to track the activity in the private room set up for the user they want to track. When the user they want to track has a private room active, the scanner will periodically scan the private room for:

- Information about the users that entered the room
- The outfits that the users were wearing when the scanner was active, including GA and AP.
- Supports **3D room view**: view the full room and furniture. _(Note: due to IMVU limitations, you cannot see exactly where or what users have interacted with.)_

**Important:** Scanning will only occur when the private room set up for the user being tracked is active. When the private room is not active, the scanner will not scan.

## Key Features

- Automatically scans the private room activity set up for the user
- Scanning occurs regularly every **5 to 10 minutes** when the private room is active
- Tracks the users that entered the private room
- Tracks the outfits that the users were wearing when the scanner was active
- No need to manually scan the private room
- Tracking depends on the plan that the user is on

    <AccordionGroup>
      <Accordion title="Room Visits">
        **Definition**: This metric reflects the total number of visits a user has made into various rooms over the selected period.

        **How It Works**: Each time searched user enters a room, it counts as a visit regardless how many times user leaves and joins.

        **Purpose**: Understanding the number of room visits can help you understand how frequently searched user are engaging in a private room and identifying patterns in their activities.
      </Accordion>
      <Accordion title="Unique Rooms">
        **Definition**: This metric indicates the number of different rooms searched user has interacted within the timeframe.

        **How It Works**: Each room is counted only once regardless of how many times you entered it. For instance, if you visit Room A and Room B, that counts as two unique rooms even if you visit Room A multiple times.
      </Accordion>

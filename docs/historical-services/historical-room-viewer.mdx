![Historical Room Viewer Examples](/images/historical-room-viewer_banner.png)

This tool provides an overview of a searched user public room history, including details what outfits users are wearing in those rooms. It allows you to track user-owned rooms to observe their presence and activities with data accessible for the past 3 hours. 

<Badge icon="crown" color="yellow" size="lg" shape="pill">VuArchives Premium users get nearly live data and can see current outfits in rooms</Badge>
